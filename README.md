##### **Simple To-Do List**

##### 

###### &#x20;**Description**



This project is a simple command-line To-Do List application created using Python. It allows users to manage their daily tasks by adding, viewing, updating, and removing tasks.



###### &#x20;**Features**



* &#x20;Add new tasks
* &#x20;View all tasks
* &#x20;Update an existing task
* &#x20;Remove a task
* &#x20;Handles invalid menu choices
* &#x20;Simple and easy-to-use command-line interface



###### &#x20;**Technologies Used**



* Language: Python
* Concepts: Lists, Functions, Loops, Conditional Statements, User Input



###### &#x20;**How It Works**



The program stores tasks in a Python list. A menu is displayed to the user, allowing them to choose an operation:



1\. Add Task

2\. View Tasks

3\. Update Task

4\. Remove Task

5\. Exit



The program continues running until the user chooses the Exit option.



###### &#x20;**How to Run**



1\. Install Python on your computer.

2\. Download or clone this repository.

3\. Open the project folder in a terminal.

4\. Run the program using:

python todo\_list.py



5\. Select an option from the menu and manage your tasks.



###### &#x20;**Learning Outcome**



Through this project, I practiced using Python lists, functions, loops, conditional statements, and user input. I also learned how to create a simple menu-driven command-line application.

###### 

###### &#x20;**Conclusion**



This To-Do List project is a beginner-friendly Python application that demonstrates basic task management using a command-line interface.
